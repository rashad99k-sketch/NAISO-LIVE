# مجلد بيانات GGP

يُنشئ البوت هنا ملف SQLite تلقائيًا باسم `ggp_trade_journal.sqlite3`
(أو حسب قيمة `TRADE_JOURNAL_PATH` في `.env`).

- لا تُدرج قاعدة البيانات أو ملفات `-wal`/`-shm` في Git أو ZIP.
- خُذ نسخة احتياطية قبل أي ترقية، ولا تحذف الملف؛ النظام يُرحّل الأعمدة الجديدة تلقائيًا دون فقدان السجلات.
- هذا المجلد لا يحتوي أي بيانات اعتماد.
